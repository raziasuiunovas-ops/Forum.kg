# Инструкция по добавлению форумов через Admin API

Этот скрипт добавляет три форума в систему через Admin API:
1. **Bishkek Digital Forum 2026** - Технологии в Бишкеке
2. **Fintech Forum Central Asia** - Финансы в Бишкеке
3. **Education & Innovation Summit** - Образование в Оше

## Предварительные требования

1. Убедитесь, что сервер Next.js запущен:
   ```bash
   npm run dev
   ```

2. Убедитесь, что у вас настроен Telegram бот и админ имеет доступ к чату

## Способ 1: Упрощенный скрипт (Рекомендуется)

### Шаг 1: Запустите процесс логина

```bash
node scripts/seed-forums-simple.js login
```

Этот шаг:
- Получит CSRF токен
- Отправит запрос на логин админа
- Отправит 2FA код в Telegram
- Сохранит состояние в файл `.seed-state.json`

### Шаг 2: Получите код из Telegram

Откройте Telegram и найдите бота. Он должен отправить вам 6-значный код.

### Шаг 3: Создайте форумы с кодом 2FA

```bash
node scripts/seed-forums-simple.js create <КОД>
```

Замените `<КОД>` на код, полученный из Telegram (например: `123456`).

Пример:
```bash
node scripts/seed-forums-simple.js create 123456
```

## Способ 2: Альтернативный скрипт

Если у вас возникли проблемы с первым способом, используйте альтернативный:

```bash
node scripts/seed-forums.js
```

Скрипт выведет pending token, затем запустите его снова с кодом:

```bash
node scripts/seed-forums.js <КОД>
```

## Устранение неполадок

### Ошибка: "Failed to get CSRF token"
- Убедитесь, что сервер запущен на http://localhost:3000
- Проверьте, что нет ошибок в консоли сервера

### Ошибка: "Admin login failed"
- Проверьте, что учетные данные админа правильные в `.env`
- Убедитесь, что ADMIN_LOGIN и ADMIN_PASSWORD установлены

### Ошибка: "2FA verification failed"
- Проверьте, что вы ввели правильный код из Telegram
- Убедитесь, что код не истек (коды действительны 5 минут)
- Попробуйте начать процесс заново

### Ошибка: "Telegram send failed"
- Проверьте, что TELEGRAM_BOT_TOKEN настроен в `.env`
- Проверьте, что ADMIN_TELEGRAM_CHAT_ID правильный
- Убедитесь, что бот может отправлять сообщения в чат

### Ошибка: "Forum creation failed: SLUG_ALREADY_EXISTS"
- Форумы уже существуют в базе данных
- Либо удалите существующие форумы через админ-панель
- Либо измените slug в скрипте на уникальный

## Технические детали

Скрипт использует следующие API endpoints:

1. `GET /api/v1/auth/csrf-token` - получение CSRF токена
2. `POST /api/v1/admin/login` - логин админа и отправка 2FA кода
3. `POST /api/v1/admin/verify-2fa` - верификация 2FA кода и получение сессии
4. `POST /api/v1/admin/forums` - создание форума

## Примечания

- Все даты указаны в часовом поясе Asia/Bishkek (UTC+6)
- Цены указаны в тыинах (1 сом = 100 тыинов)
- Переводы доступны на русском и английском языках
- Все форумы создаются со статусом PUBLISHED
