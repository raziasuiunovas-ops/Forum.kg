# 📱 Исправление адаптивности карточек форумов

## 🐛 Проблема

Карточки форумов в секции Events Calendar имели проблемы с отображением на мобильных устройствах:
- Изображение справа занимало слишком много места на малых экранах
- Контент был сжат и плохо читался
- Не было четкого разделения между мобильной и десктопной версией
- Пропорции карточек не адаптировались под разные устройства

## ✅ Решение

Обновлен файл `components/landing/EventsCalendar.tsx` с полной адаптивностью.

### Основные изменения:

#### 1️⃣ Мобильная версия (< 640px)
```tsx
// Изображение сверху
<div className="block h-48 w-full sm:hidden">
  <img ... />
</div>

// Контент снизу
<div className="flex flex-1 flex-col p-4">
  ...
</div>
```

**Характеристики:**
- 📐 **Вертикальная компоновка** (flex-col)
- 🖼️ **Изображение на всю ширину** сверху (h-48)
- 📝 **Контент на всю ширину** снизу
- 🎯 **Оптимальная читаемость** текста

#### 2️⃣ Десктопная версия (≥ 640px)
```tsx
// Контент слева
<div className="flex flex-1 flex-col p-4 sm:p-5">
  ...
</div>

// Изображение справа
<div className="hidden sm:block w-[38%]">
  <img ... />
</div>
```

**Характеристики:**
- ↔️ **Горизонтальная компоновка** (flex-row)
- 📝 **Контент занимает 62%** ширины
- 🖼️ **Изображение занимает 38%** ширины
- 🎯 **Сбалансированные пропорции**

#### 3️⃣ Улучшенный grid layout
```tsx
// Было:
<div className="grid gap-5 lg:grid-cols-[1.25fr_1fr]">

// Стало:
<div className="grid gap-5 lg:grid-cols-[1.25fr_1fr] xl:grid-cols-[1.3fr_1fr]">
```

**Преимущества:**
- 📱 **Mobile**: одна колонка (100%)
- 💻 **Tablet/Desktop (lg)**: 1.25fr + 1fr
- 🖥️ **Large Desktop (xl)**: 1.3fr + 1fr (еще лучше пропорции)

#### 4️⃣ Адаптивная высота featured карточки
```tsx
// Было:
<div className="min-h-[460px] sm:p-8 lg:min-h-[540px]">

// Стало:
<div className="min-h-[460px] sm:min-h-[500px] sm:p-8 lg:min-h-[540px]">
```

**Плавный переход:**
- 📱 **Mobile**: 460px
- 📱 **Small tablet**: 500px
- 💻 **Large**: 540px

## 🎯 Ключевые принципы адаптивности

1. **Mobile First** - начинаем с мобильной версии
2. **Progressive Enhancement** - добавляем функции для больших экранов

4. **Плавные переходы** - анимации работают на всех устройствах
5. **Контентная иерархия** - важное всегда видно первым
