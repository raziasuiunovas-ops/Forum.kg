### 📐 Дизайн системы

**Общие стили (идентичны Select):**

**Нормальное состояние:**
- Белый фон с градиентом (from-white to-slate-50/30)
- Серая обводка 2px (border-slate-200)
- Иконка календаря/часов слева (text-slate-400)
- Шрифт: semibold, text-sm

**При наведении:**
- Синяя обводка (border-primary/60)
- Градиентный фон (from-primary/5 to-primary/10)
- Увеличенная тень (shadow-md)

**При фокусе:**
- Синяя обводка (border-primary)
- Белый фон
- Большая тень (shadow-lg)
- Синее кольцо (ring-4 ring-primary/20)

**Нативный picker:**
- Скрыт по умолчанию (opacity-0)
- Появляется при наведении на область справа
- Синий фон при наведении (bg-primary/10)

### 💻 Формат использования:

```tsx
import { DateInput, DateTimeInput } from '../ui'

// Поле даты
<DateInput
  value={date}
  onChange={(e) => setDate(e.target.value)}
  aria-label="Выберите дату"
  className="w-full sm:w-48" // опционально
/>

// Поле даты и времени
<DateTimeInput
  value={datetime}
  onChange={(e) => setDatetime(e.target.value)}
  aria-label="Выберите дату и время"
  className="w-full" // опционально
/>
```
