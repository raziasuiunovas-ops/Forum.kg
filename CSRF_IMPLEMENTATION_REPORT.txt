 3. SECURITY FEATURES
═══════════════════════════════════════════════════════════════════════

🔒 Double Submit Cookie Pattern
   - Token в HttpOnly cookie: csrf_token
   - Token в header: X-CSRF-Token
   - Требуется совпадение обоих значений

🔒 Origin/Referer Validation
   - Same-origin: разрешено
   - Cross-origin: блокировано (403)
   - Missing Origin/Referer: разрешено (защита от old browsers)

🔒 Constant-Time Comparison
   - XOR loop для предотвращения timing attacks
   - Заменяет crypto.timingSafeEqual (Edge incompatible)

🔒 Selective Protection
   - Protected methods: POST, PUT, PATCH, DELETE
   - Safe methods: GET, HEAD, OPTIONS - bypass
   - Skip list: /auth/phone/* (rate-limited endpoints)

🔒 Cookie Security
   - httpOnly: true (защита от XSS)
   - secure: true (production HTTPS only)
   - sameSite: 'strict' (дополнительная CSRF защита)
   - maxAge: 24 hours
