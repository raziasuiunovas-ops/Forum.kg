# Обновление выпадающих меню в админ-панели

## ✅ Выполнено

Все нативные `<select>` элементы в админ-панели заменены на кастомный компонент `Select` с единым стилем.

### Измененные файлы:

1. ✅ **Dashboard.tsx** - выпадающее меню выбора форума
2. ✅ **Orders.tsx** - фильтр статусов заказов и статус возврата в отменах  
3. ✅ **Scanner.tsx** - выбор форума, приложения оплаты, статус сверки
4. ✅ **Tickets.tsx** - фильтры форума и статуса
5. ✅ **Users.tsx** - фильтр статусов пользователей
6. ✅ **Analytics.tsx** - выбор форума для аналитики
7. ✅ **Audit.tsx** - фильтр по дате и сотруднику
8. ✅ **Settings.tsx** - выбор социальных сетей
9. ✅ **Staff.tsx** - выбор роли сотрудника
10. ✅ **Notifications.tsx** - выбор типа и аудитории

**Итого:** 10 файлов обновлено, все выпадающие меню теперь используют единый стиль.

### Компонент Select

Путь: `components/admin/Select.tsx`  
Экспорт: `components/admin/ui.tsx` (как `Select`)

**Особенности:**
- ✅ Единый стиль со скругленными углами (rounded-xl)
- ✅ Синяя обводка с градиентом при открытии (border-primary)
- ✅ Плавные анимации (fade-in, zoom-in, slide-in)
- ✅ Галочка при выборе (Check icon из lucide-react)
- ✅ Hover эффекты на опциях
- ✅ Поддержка клавиатурной навигации:
  - **Стрелки вверх/вниз** - навигация по опциям
  - **Enter** - выбор опции
  - **Escape** - закрытие меню
- ✅ Автоматическое закрытие при клике вне элемента
- ✅ Доступность (ARIA атрибуты: aria-label, aria-haspopup, aria-expanded, role="listbox")
- ✅ Автоматический скролл к выделенной опции

### Формат использования:

```tsx
import { Select } from '../ui'

<Select
  value={selectedValue}
  onChange={(value) => setSelectedValue(value)}
  options={[
    { value: 'option1', label: 'Опция 1' },
    { value: 'option2', label: 'Опция 2' }
  ]}
  aria-label="Описание для скринридеров"
  placeholder="Выберите..." // опционально
  className="w-full" // опционально
/>
```

### Дизайн системы

**Закрытое состояние:**
- Белый фон с градиентом (from-white to-slate-50/30)
- Серая обводка (border-slate-200)
- При наведении: синяя обводка (border-primary/60) + градиент (from-primary/5 to-primary/10)

**Открытое состояние:**
- Синяя обводка (border-primary)
- Градиентный фон (from-primary/5 to-primary/10)
- Тень и кольцо (shadow-lg ring-4 ring-primary/20)
- Иконка шеврона поворачивается на 180°

**Выпадающий список:**
- Белый фон с закругленными углами
- Синяя рамка (border-primary/20)
- Выбранная опция: синий фон (bg-primary) с белым текстом
- Hover: светло-синий фон (bg-primary/10)

## Результат

🎉 Теперь все выпадающие меню в админ-панели имеют единый, современный стиль как на второй фотографии:
- Синяя обводка с градиентным фоном при открытии
- Закругленные углы (rounded-xl)
