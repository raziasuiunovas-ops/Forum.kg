# Обновление выпадающих меню в админ-панели

## Выполнено

Все нативные `<select>` элементы в админ-панели заменены на кастомный компонент `Select` с единым стилем.

### Измененные файлы:

1. **Dashboard.tsx** - выпадающее меню выбора форума
2. **Orders.tsx** - фильтр статусов заказов и статус возврата в отменах
3. **Scanner.tsx** - выбор форума, приложения оплаты, статус сверки
4. **Tickets.tsx** - фильтры форума и статуса (уже использовали Select)
5. **Users.tsx** - фильтр статусов пользователей (уже использовал Select)
6. **Analytics.tsx** - выбор форума для аналитики
7. **Audit.tsx** - фильтр по дате и сотруднику
8. **Settings.tsx** - выбор социальных сетей
9. **Staff.tsx** - выбор роли сотрудника (уже использовал Select)
10. **Notifications.tsx** - выбор типа и аудитории (уже использовал Select)

### Компонент Select

Путь: `components/admin/Select.tsx`

**Особенности:**
- ✅ Единый стиль со скругленными углами (rounded-xl)
- ✅ Синяя обводка при фокусе (border-primary)
- ✅ Плавные анимации
- ✅ Галочка при выборе (Check icon)
- ✅ Hover эффекты на опциях
- ✅ Поддержка клавиатурной навигации (стрелки вверх/вниз, Enter, Escape)
- ✅ Автоматическое закрытие при клике вне элемента
- ✅ Доступность (ARIA атрибуты)

### Формат использования:

```tsx
<Select
  value={selectedValue}
  onChange={(value) => setSelectedValue(value)}
  options={[
    { value: 'option1', label: 'Опция 1' },
    { value: 'option2', label: 'Опция 2' }
  ]}
  aria-label="Описание"
  className="optional-classes"
/>
```

## Результат

Теперь все выпадающие меню в админ-панели имеют единый, современный стиль:
- Синяя обводка с градиентным фоном при открытии
- Закругленные углы
- Плавные анимации
- Галочка для выбранного элемента
- Улучшенный UX

Старый стиль `select` из `ui.tsx` остается для совместимости, но больше не используется в коде.
