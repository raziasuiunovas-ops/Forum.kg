# Исправление расположения фильтров в журнале аудита

## Проблема
В разделе "Журнал аудита" админ-панели три поля фильтрации (поиск, дата и выпадающий список сотрудников) были расположены некорректно.

## Решение
Обновлен компонент `components/admin/pages/Audit.tsx`:

### Изменения:

1. **Добавлен контейнер для toolbar**:
   - Используется `div` с классами `flex flex-wrap gap-2 sm:justify-end`
   - Это обеспечивает правильное выравнивание полей на всех размерах экрана

2. **Адаптивные ширины полей**:
   - Дата: `w-full sm:w-44` (полная ширина на мобильных, фиксированная на десктопе)
   - Сотрудник: `w-full sm:w-52` (полная ширина на мобильных, фиксированная на десктопе)

3. **Структура расположения**:
   - На мобильных устройствах: все 3 поля идут друг под другом во всю ширину
   - На планшетах и десктопе (sm:): 
     - Первая колонка: поле поиска
     - Вторая колонка: дата и селект сотрудника выровнены справа

### Код изменений:

```tsx
toolbar={
  <div className="flex flex-wrap gap-2 sm:justify-end">
    <input 
      type="date" 
      aria-label="Дата" 
      className={`${field} w-full sm:w-44`} 
      value={day} 
      onChange={(e) => setDay(e.target.value)} 
    />
    <select 
      aria-label="Сотрудник" 
      className={`${field} w-full sm:w-52`} 
      value={actor} 
      onChange={(e) => setActor(e.target.value)}
    >
      <option value="all">Все сотрудники</option>
      {actors.map((a) => <option key={a}>{a}</option>)}
    </select>
  </div>
}
```

## Результат
- ✅ Все три поля фильтрации корректно расположены
- ✅ Адаптивная верстка для мобильных и десктопных устройств
- ✅ Не затронуты другие страницы админки
