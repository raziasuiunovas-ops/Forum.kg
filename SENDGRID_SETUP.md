# Настройка SendGrid для восстановления пароля

## ✅ Статус: НАСТРОЕНО И РАБОТАЕТ!

SendGrid уже настроен и успешно отправляет письма с восстановлением пароля.

## Текущая конфигурация

В файле `.env` добавлены следующие переменные:

```env
SENDGRID_API_KEY=your_sendgrid_api_key_here
SENDGRID_FROM_EMAIL=your_email@gmail.com
```

## Что работает

1. ✅ **SendGrid API ключ** - проверен и работает
2. ✅ **Email отправитель** - верифицирован (raziasuiunovaa@gmail.com)
3. ✅ **Лимит** - 100 писем в день на бесплатном плане
4. ✅ **Email сервис** - `lib/services/email.service.ts` полностью настроен
5. ✅ **API роуты**:
   - `POST /api/v1/auth/password/request-reset` - запрос восстановления пароля
   - `POST /api/v1/auth/password/reset` - установка нового пароля
6. ✅ **UI страницы**:
   - `/[locale]/forgot-password` - форма запроса восстановления
   - `/[locale]/reset-password` - форма установки нового пароля
7. ✅ **Компоненты**:
   - `components/auth/ForgotPasswordForm.tsx`
   - `components/auth/ResetPasswordForm.tsx`

## Как тестировать

### 1. Запустите проект
```bash
npm run dev
```

### 2. Перейдите на страницу входа
```
http://localhost:3000/ru/login
```

### 3. Нажмите на "Забыли пароль?"
Или перейдите напрямую:
```
http://localhost:3000/ru/forgot-password
```

### 4. Введите email и запросите восстановление
- Введите email (например: `raziasuiunovaa@gmail.com` или любой другой)
- Нажмите "Отправить ссылку"
- Письмо придет на указанный email в течение нескольких секунд

### 5. Проверьте почту
- Откройте письмо с темой "Восстановление пароля — FORUM.KG"
- **Важно**: если письмо не пришло, проверьте папку "Спам"
- Нажмите на кнопку "Восстановить пароль" в письме

### 6. Установите новый пароль
- Введите новый пароль (минимум 8 символов, минимум одна буква и одна цифра)
- Подтвердите пароль
- Нажмите "Сменить пароль"
- После успешной смены вы будете перенаправлены на страницу входа

### 7. Войдите с новым паролем
- Используйте email и новый пароль для входа

## Troubleshooting

### Письмо не приходит
1. Проверьте папку "Спам"
2. Проверьте, что email верифицирован в SendGrid
3. Проверьте логи сервера на наличие ошибок
4. Убедитесь, что не превышен лимит 100 писем в день

### Ошибка при отправке
1. Проверьте, что API ключ правильный
2. Проверьте, что FROM_EMAIL верифицирован
3. Проверьте подключение к интернету
4. Посмотрите логи в консоли разработчика
