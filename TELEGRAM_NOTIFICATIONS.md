# Уведомления в Telegram о покупке билетов

## Обзор

При успешной оплате билета пользователь автоматически получает уведомление в Telegram с полной информацией о заказе, если он подключил бот `@Forum_kg_bot`.

## Как это работает

### 1. Webhook оплаты (Finik)

Файл: `app/api/v1/payments/webhooks/finik/route.ts`

После успешной обработки платежа:
- Система отправляет Web Push уведомление (как раньше)
- **НОВОЕ:** Если у пользователя подключен Telegram, отправляется детальное сообщение в бот

### 2. Функция отправки уведомлений

Файл: `lib/integrations/telegram.ts`

Новая функция `sendTicketPurchaseNotification()` формирует красивое сообщение с:
- ✅ Статусом оплаты
- 📋 Номером заказа
- 🎫 Названием форума и датой
- 💰 Количеством билетов и суммой
- 📱 Инструкцией где найти QR-коды

### 3. Формат сообщения

```
🎉 Оплата прошла успешно!

📋 Информация о заказе:
• Заказ: ORD-123456
• Форум: Название форума
• Дата: 15 декабря 2026 г., 10:00
• Билетов: 2 билета
• Сумма: 1500.00 KGS

✅ Ваши билеты готовы! QR-коды доступны в личном кабинете на сайте FORUM.KG

📱 Не забудьте показать QR-код на входе!

Спасибо за покупку! До встречи на форуме! 🚀
```

## Настройка

### Переменные окружения

В `.env` уже настроены:
```env
TELEGRAM_BOT_TOKEN=9258325267:AAFKYS1BlLADCGtbWXX9_fIWc8oNbjfMdfA
TELEGRAM_BOT_ID=9258325267
TELEGRAM_BOT_USERNAME=Forum_kg_bot
```

### База данных

Используется таблица `TelegramConnection`:
- `userId` - ID пользователя
- `chatId` - Telegram chat ID для отправки сообщений
- `connectedAt` - Дата подключения

## Безопасность

- Используется существующий модуль `telegram.ts` с защитой от инъекций
- Код не логируется для предотвращения утечки чувствительных данных
- Таймаут 10 секунд предотвращает зависание
- Ошибки отправки не блокируют основной процесс оплаты

## Тестирование

Для тестирования:
1. Пользователь должен подключить Telegram бот `@Forum_kg_bot`
2. Оформить заказ билета
3. Оплатить через Finik
4. Получить уведомление в Telegram
